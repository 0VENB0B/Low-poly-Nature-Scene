# Low poly nature scene


This is a personal Unity project created to **showcase the 3D models I made while learning Blender for the first time**.

The main goal of this project is to practice:
- Basic modeling and low poly art in **Blender**
- Importing and using 3D models inside **Unity**
- Lighting, URP (Universal Render Pipeline), and basic scene setup
All models in this project were created by me as part of my first learning journey with Blender.

Feel free to explore, use, and learn from them!

## 🎮 Play Test – Multiplayer Support



This project supports multiplayer for exploring 3D models together with friends.

### ✅ Current Playtest Features:

- Can walk around with other player
- Interact object in scene

### 🧪 How to Play with Friends via Hamachi

1. **Install Hamachi**
    
    Download and install **Hamachi** from [here](https://www.vpn.net/)
    
2. **Create a Hamachi Network**
    - Open Hamachi and create a new network
    - Share the **Network Name** and **Password** with your friends
3. **Connect via Hamachi**
    
    All players who wish to join the game must connect to the same Hamachi network
    
4. **Open the Project in Unity**
    
    Open the project in Unity and load the scene you want to test
    
5. **Start the Game**
    
    Press **Play** to start the game and ensure that players can join from the same Hamachi network
### 🛠️ Multiplayer Framework
This project uses:
[Mirror Networking]
